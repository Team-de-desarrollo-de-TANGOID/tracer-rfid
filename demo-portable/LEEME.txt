RFID TRACER — TRAZABILIDAD DE ACTIVOS
=====================================

Desarrollado e implementado por TANGOID SRL.

INSTALACIÓN
-----------
1. Ejecute RFID-TRACER-Setup-x.x.x.exe
2. Siga el asistente (puede elegir la carpeta de instalación).
3. Abra RFID TRACER desde el acceso directo del escritorio o el menú Inicio.

DATOS
-----
La base SQLite se guarda en la carpeta "data" junto al ejecutable.
Puede respaldar esa carpeta para conservar inventario y configuración.

ACCESO INICIAL
--------------
Usuario: Administrador
Contraseña: administrador

Cambie la contraseña desde Configuración → Usuarios y roles.

LECTOR CHAINWAY R3 (alta de tags)
---------------------------------
- Conecte el R3 por USB.
- Requiere Java 17 o superior instalado en Windows (para el bridge USB).
- En Agregar activos, la barra lateral derecha muestra el estado del lector
  y permite ajustar la potencia de las antenas.
- Al apoyar toallas sobre el lector, los EPC se cargan automáticamente.

LECTOR DE PUERTA FX9600
-----------------------
Configure la IP y credenciales en Configuración → Lector de puerta.

REQUISITOS
----------
- Windows 10/11 (64 bits)
- Java 17+ (solo necesario para el lector USB R3)
- No requiere internet para el uso local
