# Acceso a paneles

## Aplicación RFID TRACER

1. Abra la aplicación instalada (o en desarrollo: `npm run dev`).
2. Inicie sesión con:

| Campo | Valor |
|-------|-------|
| Usuario | `Administrador` |
| Contraseña | `administrador` |

3. Cambie la contraseña en **Configuración → Usuarios y roles**.

## Alta de tags con Chainway R3

1. Instale **Java 17+** en el PC.
2. Conecte el R3 por USB.
3. Vaya a **Activos → Agregar**.
4. En la barra lateral derecha verá el estado del lector y el control de potencia.
5. Apoye las toallas sobre el lector: los EPC se agregan solos al lote.

## Lector Zebra FX9600

Ver `docs/CREDENCIALES.md` para panel web (`admin` / `Admin1234$`) y SSH/API (`rfidadm`).
